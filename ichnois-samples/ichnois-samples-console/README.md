# IchnoisCore Sample Console

Sample application showing how to use IchnoisCore manually without any framework integration.

## How to run? 

To see events triggered in this sample application in your IchnoisCore dashboard, go to `src/main/java/io/ichnois/samples/console/Main.java` and replace the test DSN with your own DSN. 

Then, execute a command from the module directory:

```
../../gradlew run
```
