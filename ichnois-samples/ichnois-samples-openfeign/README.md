# IchnoisCore Sample OpenFeign

Sample application showing how to use instrument Feign HTTP client with IchnoisCore.

## How to run? 

To see transactions triggered in this sample application in your IchnoisCore dashboard, go to `src/main/java/io/ichnois/samples/openfeign/Main.java` and replace the test DSN with your own DSN. 

Then, execute a command from the module directory:

```
../../gradlew run
```
