# IchnoisCore Sample JUL

Sample application showing how to use IchnoisCore wit Java Util Logger.

## How to run? 

To see events triggered in this sample application in your IchnoisCore dashboard, go to `src/main/resources/ichnois.properties` and replace the test DSN with your own DSN. 

Then, execute a command from the module directory:

```
../../gradlew run
```
